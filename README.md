# 🩸 Lifelink - Blood Donation Platform

Lifelink is a blood donation and emergency response platform that connects blood donors with hospitals in need.

## 🎯 Features

- 👤 **Donor Management** - Register, profile, donation history
- 🏥 **Hospital Dashboard** - Blood inventory, emergency requests
- 🗺️ **Location Services** - Find nearby donors and hospitals
- 🔔 **Real-time Notifications** - Emergency alerts
- 📊 **Analytics** - Blood usage trends and reports

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Real-time:** Socket.io
